# A3 Finance V26 — Booking Dispatch Centre

Updated Booking Management into a full operational dispatch workspace.

## Main improvements

- Operations KPI cards: today, pending, confirmed and unassigned
- Live booking queue with improved active/unread/urgent states
- Clearer customer, service, journey, fare and payment presentation
- Full pickup and destination address support
- Driver assignment and internal notes controls
- Sticky action bar with WhatsApp, Print, Close, Save and Delete
- Responsive tablet and mobile layout
- Existing booking API and saved data remain unchanged

## Deployment

Upload the contents of this FINANCE folder to the GitHub repository used by Vercel. Keep existing Vercel environment variables.
