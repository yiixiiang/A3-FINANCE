# A3 Finance v5 Website CMS

## Added
- Food stall opening and closing times
- Closed days and temporary closure
- Stall phone, WhatsApp, address and Google Maps URL
- Reviews for Food, Nightclub and Limousine catalogues
- Review moderation: Pending, Approved, Rejected and Hidden
- Featured and verified reviews
- Admin replies
- Public API now returns `stalls`, `items` and approved `reviews`

## Usage
1. Open Finance > Website Catalogue > Food.
2. Add or edit a stall and enter Open time, Close time and Closed days.
3. Add a review in the Reviews section.
4. Set the review to Approved to publish it.
5. Save and run Cloud Sync.

The Food website calculates Open now / Closed now using Singapore time.
