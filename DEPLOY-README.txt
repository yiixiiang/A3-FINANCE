A3 FINANCE — CLEAN VERCEL DEPLOYMENT

This archive has package.json and app/page.tsx at its root.
It intentionally contains no vercel.json, no .vercel directory, and no GitHub Actions deployment override.

Recommended deployment:
1. Extract this ZIP.
2. Push the extracted files to a NEW GitHub repository. package.json must be visible at the repository root.
3. In Vercel choose Add New > Project and import that repository.
4. Framework Preset: Next.js.
5. Root Directory: ./
6. Build Command, Output Directory, Install Command: leave all as Default/blank.
7. Deploy.

Do not upload the ZIP itself as a static folder and do not choose Other/Static as the framework.
