# Finance V32

- Vehicle Rate vehicle types now have visible Edit and Delete controls.
- Renaming a vehicle type also updates the matching Fleet & Photos record.
- Deleting a vehicle type removes its rate column and matching fleet record after confirmation.
- Public rate API aligns fleet capacities by normalized vehicle name with index fallback.
- Public API publishes exact passenger and luggage capacities configured in Fleet & Photos.
- Hourly Disposal publishes minimum_hours: 3.
