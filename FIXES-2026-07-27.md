# Responsive and optimization fixes

- Added explicit mobile viewport and browser theme metadata.
- Hardened layouts for 320px+ screens and safe-area insets.
- Simplified crowded header controls on tablets and phones.
- Increased touch targets and prevented mobile input zoom.
- Made tables horizontally scrollable without breaking page width.
- Converted mobile dialogs into usable bottom sheets with sticky headers/actions.
- Improved responsive action bars, document controls, cards, and navigation.
- Added reduced-motion support, print cleanup, numeric alignment, and rendering containment.

## Validation

`npm run typecheck` passes with the bundled dependencies.

The full Next.js build was attempted. Source compilation was blocked only because the build environment returned HTTP 503 while downloading `@next/swc-linux-x64-gnu`. Run `npm ci && npm run check` in a normal networked Node environment.
