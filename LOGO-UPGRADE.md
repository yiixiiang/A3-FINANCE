# A3 Group SG Logo Upgrade

The supplied A3 Group SG logo is installed globally at:

`public/brand/a3-group-sg-logo.png`

It is applied to:
- Main sidebar branding
- Login page branding
- Browser icon / shortcut icon
- Apple touch icon
- Open Graph preview metadata

Run `npm install`, then `npm run typecheck` and `npm run dev`.
