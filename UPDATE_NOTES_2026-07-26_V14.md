# FINANCE1 V14 Update

## Job-based driver payout
- Replaced the driver/vehicle payout matrix with a job passenger-tier payout table.
- Default job payout tiers:
  - 1–3 pax: SGD 30
  - 4–6 pax: SGD 35
- Tiers support Add, Edit, Delete, Save and Active/Inactive status.
- Invoice jobs now include a Pax field.
- Assigning a driver applies the fixed payout from the job passenger tier, not from the driver or vehicle.
- Manual payout remains available when no tier matches.

## Balance Sheet corrections included
- Every partner has independent records and balances.
- AB0003 exists only under Balance Sheet → BP.
- Partner J has independent A, B, BP and X opening balances.
- J calculations: A = Self Key × 3%, B = Self Key × 2%, BP = Self Key × 2%, J = A Total − B Total, X + J = J's own X Balance + J Balance.
- Add and Deduct are explicit transaction types.
- WhatsApp, Telegram and WeChat sharing added.
- Shared messages do not disclose Total Self Key Amount.
