# FINANCE1 V24 — Full Complete Upgrade

V24 consolidates the full application and every Supabase database upgrade into one standalone package.

## Installation

Run only these files in order:

1. `01-OPEN-AND-RUN-COMPLETE-SQL.cmd`
2. `02-SETUP-BUILD-AND-DEPLOY.cmd`
3. `03-PUSH-GITHUB-SAFELY.cmd`
4. `04-VERIFY-COMPLETE-UPGRADE.cmd`

No earlier version or incremental SQL upgrade is required.
